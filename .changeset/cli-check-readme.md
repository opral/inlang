`inlang check --unused-messages` supports i18next projects with `@inlang/plugin-i18next` 6.5.0 or later. With an older i18next plugin, it asks to update the plugin's module URL. The docs say which checks work with i18next, next-intl and Paraglide JS, and explain how to move from `validate` and `lint` to `check`.
