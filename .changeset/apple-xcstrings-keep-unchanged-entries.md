Saving a project no longer rewrites the whole `.xcstrings` catalog. The export keeps the text of every string that didn't change, including Xcode's formatting, key order, `state` and `extractionState` (an edited translation gets `"state" : "translated"`), and keeps `comment`, `isCommentAutoGenerated` and `shouldTranslate` of strings, so that git only shows the edited translations. New strings and locales are inserted where Xcode sorts them.
